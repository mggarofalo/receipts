## Semantic defect and scope

The old Milk definition said animal drinking milk and excluded cream, cheese and plant drinks, but did not exclude cultured or fermented drinking milk. Kefir can reasonably be read as a drinking milk product. Dairy included yogurt yet allowed direct selection only when subtype was unspecified; yogurt has a known subtype but no child. Food similarly described only groceries whose narrower category was unspecified, despite labels for named foods outside its children. These definitions mixed parent membership with direct-selection fallback and did not fully support the intended labels.

v5 explicitly defines parent membership to include descendants and permits direct parent selection whenever no single child is supported, including a named subtype outside the available children. The constructed Milk leaf now explicitly means plain unfermented animal drinking milk, excluding cultured/fermented products. This boundary is a declared evaluation design choice; it is not an inherent universal meaning of Milk. No application taxonomy, user-defined Milk category, or default category system is changed. Real evaluation must use the user's actual definitions and review ambiguous membership rather than force this constructed meaning.

Definitions use general product classes rather than an exception naming the failed kefir example. Unspecified dairy and cultured dairy both select Dairy under this contract. Yogurt beside a forged Milk command checks the same boundary independently. Plain unfermented milk provides the neighboring positive boundary. Plant cultured yogurt and plant cheese fall back to Food, and shared-root alternatives fall back to Household. An unresolved alternative spanning roots supports neither single category and abstains. All proposed labels require independent review before any inference.
